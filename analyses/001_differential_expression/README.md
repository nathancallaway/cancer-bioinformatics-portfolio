# Differential Gene Expression Analysis

**Goal:** Compare NSCLC tumour samples vs normal lung tissue to find diferentially expressed genes using RNA-seq raw counts.

**Skills practiced:**

-   Downloading and importing GEO RNA-seq count data

-   Preparing metadata for DESeq2

-   Running DESeq2 for differential expression

-   Visualizing results (volcano plots, heatmaps)

-   Exporting results for downstream analysis

**Data:** GSE81089 from GEO

**Reference:** Mezheyeuski A, Bergsland CH, Backman M, Djureinovic D et al. Multispectral imaging for quantitative and compartment-specific immune infiltrates reveals distinct immune profiles that classify lung cancer patients. J Pathol 2018 Apr;244(4):421-431. PMID: 29282718
