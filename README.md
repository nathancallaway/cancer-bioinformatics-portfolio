# cancer-bioinformatics-portfolio

#### Author: Nathan Callaway

------------------------------------------------------------------------

This repository contains small projects I use to learn skills in both R coding and cancer bioinformatics. These projects are intended for training purposes and not for publication.

Projects are kept intentionally basic, small, and simple. The focus is on developing skills used in computational biology workflows, and practicing these workflows using public datasets.

Analyses intended:

-   RNA-seq quality control and analysis

-   Differential expression

-   Data visualisation
